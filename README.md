# My dotfiles

I am using this dotfiles with GNOME and Swaywm.

- DE/WM: GNOME or swayfx
- Bar: waybar
- Terminal: kitty
- Launcher: wofi
- Logout Manager: wlogout
- Background: https://unsplash.com/photos/snow-covered-top-mountain-on-grayscale-photo-tb49PTdW1ZM
- Notification Daemon: mako
- Fonts: JetBrainsMono Nerd Font

## Required packages

```
stow swayfx waybar kitty wofi wlogout mako wlsunset vim network-manager-applet blueman starship grim nwg-clipman
```

## Installation

1. Download required packages:


2. Clone repo inside home folder.
3. `cd ~/dotfiles`
4. `stow .`
